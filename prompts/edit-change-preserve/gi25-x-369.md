```text
生成一张东方自然主义 Editorial Design 海报，采用「夹缝构图 / Interval Composition」。

画面左右分别由两个尺度巨大的自然材质实体进入画幅，并被画面边缘裁切。两侧主体向中央挤压，在中间形成一条从顶部贯穿到底部的狭窄纵向负空间。中央裂隙是整张海报真正的视觉主角。

裂隙不要完全笔直，可以呈缓慢自然的 S 型收放关系：顶部略宽，中部收紧，下部再次打开。内部保持明亮、干净、有空气感，不填入复杂风景。左右巨大材质使用【左侧巨大材质】与【右侧巨大材质】，重点表现真实的大尺度结构、连续纹理和自然表面质感。不要让微小纹理压过整体构图。

始终遵循：先看到巨大形体，再看到材质细节。

两侧主体可以形成轻微差异，例如一侧更深、更重、更粗粝，另一侧更浅、更透光或更柔和，避免完全镜像。在中央裂隙底部加入一个比例极小的【底部微小生命元素】，例如新芽、蕨叶、苔藓、种子或细草。生命元素只占画面的极小面积，通过“大尺度自然实体”与“微小生命”形成明显比例反差，让画面产生叙事感。

使用大型英文 Serif Typography：【英文标题】标题横跨左右材质与中央裂隙。

文字根据背景明暗自然切换深浅颜色：深色材质区域使用暖米白文字，亮色裂隙区域使用深墨灰文字。允许材质边缘轻微遮挡部分字母，形成清楚的二维编辑层级，但保持整体可读。中央裂隙内部加入较小的纵向中文标题【主题】。中文使用纤细、克制、具有东方骨架的现代宋体或文化出版字体，不使用巨大毛笔书法。

加入极少量辅助文案【辅助文案】，使用小字号散布在材质边缘或留白区域，不形成普通信息框，不加入无意义英文。整体配色使用【主色调】，保持低饱和、自然、哑光和克制。画面应具有高级艺术展览海报、独立出版物、自然材料研究与 Editorial Design 气质。

整体视觉公式：左右巨大实体 + 中央纵向负空间 + 底部微小生命 + 跨层大型 Typography + 大面积低信息区域

最终效果必须让人在缩略图状态下依然首先看到“两侧巨大形体夹出一道明亮裂隙”，近看后才发现材质纹理、生命细节与小型文字。

避免：普通风景摄影、旅游海报、主体塞满中央、复杂背景、满屏纹理、密集裂纹、大量植物、鲜艳颜色、强 HDR、CGI 材质、3D Typography、无意义英文和过度装饰。

四槽示例：石隙（岩层与新生）/ 冰隙（冰层与萌芽）/ 林隙（古树与蕨叶）/ 土隙（土层与发芽）
```
